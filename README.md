# Vendor List Manager

Vendor வாரியான பொருள் பட்டியல், Buy / Send நிலை, CSV இறக்குமதி, மற்றும் PDF/WhatsApp பகிர்வுக்கான எளிய Web செயலி.

## GitHub Pages மூலம் இயக்க
1. இந்த Repository-ல் `index.html` கோப்பு இருப்பதை உறுதி செய்யவும்.
2. GitHub Repository-ல் **Settings → Pages** செல்லவும்.
3. **Branch**-ல் `main` மற்றும் **Folder**-ல் `/ (root)` தேர்ந்தெடுத்து **Save** செய்யவும்.
4. சில நிமிடங்களில் வழங்கப்படும் `https://<username>.github.io/<repo-name>/` இணைப்பைத் திறந்து பயன்படுத்தவும்.
